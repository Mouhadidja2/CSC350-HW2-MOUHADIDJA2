# MiniGit Course Project

This repository contains the continuing course project for Homework 2 through Homework 6.

## Project progression

- Homework 2: Git-based user needs and user requirements
- Homework 3: Add future assignment work when released
- Homework 4: Add future assignment work when released
- Homework 5: Add future assignment work when released
- Homework 6: Add future assignment work when released

## Student workflow

1. Fork this repository on GitHub.
2. Clone your fork to your computer.
3. Add the instructor repository as `upstream`.
4. Complete assignments in the `submissions` directory.
5. Commit and push your work to your fork.
6. Synchronize your fork before beginning each new homework.

Do not edit files in the `assignments` directory unless an assignment explicitly tells you to do so.
